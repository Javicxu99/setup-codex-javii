# Archive session

Summarize the current Codex conversation into `docs/codex-session-notes.md`.

Rules:

- Write curated project memory, not a raw transcript.
- Include date, session topic, decisions, useful context, files or areas affected, validation, follow-ups, and risks.
- Do not include secrets, credentials, private tokens, raw logs with sensitive data, or unreviewed transcript dumps.
- If the conversation produced no durable project context, say that no archive update is needed.
- Keep the entry short enough to be useful during future onboarding.

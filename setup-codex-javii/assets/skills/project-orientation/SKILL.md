# project-orientation

Usar al iniciar una tarea importante.

## Procedimiento

1. Leer `AGENTS.md`.
2. Leer `docs/project-context.md`.
3. Revisar documentos relevantes en `docs/` segun la tarea.
4. Identificar la capa afectada:
   - datos
   - entrenamiento
   - evaluacion
   - exportacion
   - optimizacion
   - despliegue
   - frontend/backend si aplica
5. Resumir:
   - estado actual
   - restricciones relevantes
   - archivos implicados
   - riesgos
   - validaciones posibles

## Regla

No modificar codigo durante la orientacion. Si aparece una ambiguedad importante, hacerla explicita antes de proponer cambios.
